About the data

Open, uneven, honest about it.

The records were written over time, in more than one shape. This page says how they're organised and how complete they are.

How complete it is

Using the files

  • data/index.json lists every record: slug, name, kind, group, region, path, the file's former name in formerly, and its top-level sections.
  • Country files are in data/countries/<slug>.json; historical ones in data/historical/, grouped by the power that held them.
  • This site serves the same files: data/index.json.
  • Continents on the browse page come from each record's own region field. For 60 records whose region is missing or more specific (for example "Maghreb" or "Southeast Europe"), the site assigns a continent from a table in _src/build.py; the data files are not changed.
  • Two shapes are in use: most modern records use sections like Name, Geography and Government; older and historical ones use lower-case keys. Both are kept as written.

Contributing

Corrections and new records are welcome as pull requests on GitHub. Run python tools/validate.py before you open one.
